# Chat-app-assignment

A clean, responsive chat application built with **React, Vite, and Tailwind CSS**, featuring interactive messaging, emoji selection, and `@mention` suggestions.

🔗 **Live Demo:** [Chat App](https://chat-app-assignment-amber.vercel.app)

## ✨ Features

- **Send Messages:** Send messages using the input field or Enter key.
- **Random Usernames:** Each message is assigned a random username.
- **Message Likes:** Like individual messages with independent counters.
- **Emoji Picker:** Select emojis using a searchable emoji picker.
- **@Mentions:** Search and select usernames by typing `@`.
- **Keyboard Navigation:** Navigate mention suggestions using arrow keys.
- **Responsive Design:** Clean UI for desktop and mobile screens.
- **Auto-scroll:** Automatically scroll to the latest message.

## 🛠️ Tech Stack

- **React** — Component-based UI
- **JavaScript (ES6+)** — Application logic
- **Vite** — Development and build tooling
- **Tailwind CSS** — Styling and responsive design
- **emoji-picker-react** — Emoji selection
- **Vercel** — Deployment

## 🚀 How to Use

1. Open the [live application](https://chat-app-assignment-amber.vercel.app/).
2. Type a message and press **Enter** or click **Send**.
3. Click 😊 to select and insert an emoji.
4. Type `@` to view and select a username.
5. Click the 👍 icon beside a message to increase its like count.

### Run Locally

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <YOUR_PROJECT_FOLDER>

```

Replace the placeholders with your actual repository URL and project folder name.
